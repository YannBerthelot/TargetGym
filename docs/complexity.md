# Choosing an environment

Every task shares one interface, so moving from one to another means changing
a name. Pick by what you want your method to face, and start with the simplest
task that shows it. Every name below works with `tg.make`, and each task's page
says what it observes and how it is scored.

```python
import target_gym as tg

env, params = tg.make("first_order")
```

## By what you want to test

| You want to test | Start with | Then |
|---|---|---|
| That a training loop runs at all | [`first_order`](environments/first_order.md) | [`cstr`](environments/cstr.md) |
| A nonlinear plant with one input | [`cstr`](environments/cstr.md) | [`ph_neutralization`](environments/ph_neutralization.md), [`unstable_cstr`](environments/unstable_cstr.md) |
| An open-loop unstable plant | [`unstable_cstr`](environments/unstable_cstr.md) | |
| Two inputs acting on coupled outputs | [`four_tank`](environments/four_tank.md) | [`distillation`](environments/distillation.md), [`boiler_drum`](environments/boiler_drum.md) |
| A response that first moves the wrong way (non-minimum phase) | [`boiler_drum`](environments/boiler_drum.md) | [`four_tank`](environments/four_tank.md) |
| Hidden state behind a few measurements | [`hvac`](environments/hvac.md) | [`glass_furnace`](environments/glass_furnace.md), [`reactor`](environments/reactor.md), [`cement_kiln`](environments/cement_kiln.md) |

| Costs priced in money | [`battery`](environments/battery.md) | [`wind_turbine`](environments/wind_turbine.md), [`hvac`](environments/hvac.md), [`reactor`](environments/reactor.md) |
| A trip on a variable nothing scores | [`compressor_surge`](environments/compressor_surge.md) | |
| An aircraft, from a level hold to paths | [`plane`](environments/plane.md) | [`plane3d_heading`](environments/plane3d_heading.md), then [`plane3d_circle`](environments/plane3d_circle.md), [`plane3d_racetrack`](environments/plane3d_racetrack.md), [`plane3d_figure8`](environments/plane3d_figure8.md) |

| Several agents sharing one cost | [`formation`](environments/formation.md) | [Multi-agent formation](multi-agent.md) |
